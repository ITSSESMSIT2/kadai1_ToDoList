# kadai1_ToDoList

岡本の課題①ToDoリスト作成です。

## 【機能概要】

ユーザーがフォームに入力した**タスク名**、**期日**、**ステータス**を受け取り、画面下部の**タスク一覧**に表示。<br>
さらに、そのタスク一覧から**削除**および**変更**が自由に行える。<br>

フォームの入力は、それぞれ<br>

- タスク名：テキスト
- 期日：カレンダーから選択
- ステータス：プルダウン形式で、**未対応**、**処理中**、**完了**の3項目から選択
  という形式で受け取る。<br>
  また、受け取ったそれぞれの要素にIDを付与し、配列に格納しているため、<br>
  ユーザーが削除や変更を行うと、配列内でも情報が更新される。<br>

## 【詰まった点・調べたこと】

### CSS

- paddingの設定<br>
  数字が一つであれば上下左右すべてに適用。二つであれば一つ目を上下に、二つ目を左右に適用。
- li項目の「・」の消し方<br>
  list-style:none;で実装できる。
- figmaでのpaddingの確認方法<br>
  altキーを押しながら確認したい要素にカーソルをあてる。

### HTML

- selectの記述方法<br>
  `<select>`の中に`<option>`を記述し、そこにプル団メニューに表示したい文字列を入れ、js内で利用したいvalueも`<option>`に設定すればよい。
- `<div>``<span>`の違い<br>
  `<div>`は同じ行に要素を持つことができないブロック要素、`<span>`は同じ行の中に複数要素を持つことができ、その要素同士を区切るインライン要素。
- js、CSSの接続方法<br>
  jsは`<body>`末尾(`<head>`でも可)に`<script src="○○.js">`を記述。<br>
  CSSは`<head>`に`<link rel="stylesheet" href="○○.css">`を記述。

### JavaScript

- addEventListerner<br>
  第一引数の動作が行われたら、第二引数の関数を、指定した箇所(.addEventListernerの前に指定した項目)で行うもの。<br>
  そのため、addEventListernerの前に来る項目はformとは限らない。
- img.src<br>
  単にimg要素をHTMLにcreateElementしても画像にはならない。<br>
  接続には.srcを利用し、使いたい画像の場所を指定することで初めて画像が表示される。<br>
  今回の場合は同ディレクトリ内に画像があるため単にVector.pngの指定で解決している。
- オブジェクトの記述<br>
  変数とオブジェクトの違いが怪しかった。複数の項目をconst変数内に収めることをオブジェクトが実現している。
- js内での`<option>`の作成<br>
  作成した`<option>`を`<select>`の中に.addすることで作成できる。
- innerText、innerHTMLの違い<br>
  innerTextは中の文字列だけを変更する。<br>
  対して、innerHTMLはHTML要素ごと変更する。<br>
  これらの要素は、既存の要素の上書きを行うものであるため、特にinnerHTML要素を利用する際は表示が崩れていないか注意する必要がある。
- **appendChild**<br>
  どの要素の中に、何を子要素として格納するのかを意識しながら作成する必要があった。<br>
  その階層の理解に時間がかかってしまったことが、今回期日を大幅に遅延した要因の一つである。<br>
  解決策として、逐一console.logで現在操作している/操作したい要素の中身を確認すること、また一旦HTML形式で求めている形をメモに起こすなどが挙げられる。
- console.dir<br>
  nodeNameなど、その要素が持つ内容をより詳しく参照したいときに利用する。<br>
  console.logが要素の中身を見るものだとすれば、console.dirはその要素の持つ性質、属性のようなものを見るものだと理解している。
- **findIndex**<br>
  findIndex()の中にはboolean式で値を返す関数を入力しておく。<br>
  指定した配列の中で、その関数がtrueになる最初の項目のインデックスを呼び出す。<br>
  今回は == を利用したが、不等式も利用できるため、Indexof（完全一致）よりも柔軟に利用できる。
- **配列と表示の一致**<br>
  特に詰まった項目。<br>
  削除機能、変更機能を実装するにあたって最大の難点は、一覧表示される内容と配列の内容を一致させ、連動させることであった。<br>
  当初は、CSSでの表示のことを考え、各入力要素同士を`<span>`で区切り、それを`<div>`に格納、さらに大きな`<div>`の中に収めるという手段を取っていた。<br>
  しかしながら、その方法での実装を行うと親要素の指定が非常に煩雑になること、また宣言する変数の量が膨大になるという問題があった。<br>
  そこで`<ul>`および`<li>`を実装することによって、コード量が大幅に減少し、配列の中にも`<li>`を格納することで解決した。<br>
  `<ul>`にイベントを設定、指定したイベント(画像へのクリック、プルダウンの項目変更)が起きれば`<li>`を軸に操作を行うように変更した。<br>
  ここにおいて、targetの親要素とaddEventListernerの指定要素の違いに混乱し非常に時間がかかってしまった。<br>
  今回の場合、targetに指定しているのは、`<li>`の中の子要素である。そのため、target.parentElementは`<li>`。<br>
  しかしながら、イベントデリゲーションを活用し、どの`<li>`に対しても同じ動作が起きてほしいためにイベントの起点は`<ul>`となっている。
- toISOString<br>
  現在時刻を取得するためのメソッド。必ずDateオブジェクトとセットで利用する（Dateオブジェクトの派生の一部）。<br>
  最初に新しいDateオブジェクトを作成し、その内容を日時文字列形式（以下参照）に変換する。
- 日付文字列形式(YYYY-MM-DDTHH:mm:ss:sssZ)<br>
  YYYY→年、MM→月、DD→日付、T→時間表示の始まりを表す、HH→時、mm→分、ss→秒、sss→ミリ秒、Z→世界標準時間として、String形式で表示すること。<br>
  この末尾のZを、世界標準時間からローカルへの時差に置き換えることで、ローカルでの時間を取得することができる。
- **querySelectorの範囲**<br>
  querySelectorの機能は、document内の要素を拾ってくることだが、その指定できる範囲はdocumentのみではない。<br>
  今回のように、親要素の中の一部を指定したい際に、対象をtaeget.parentElementとして.querySelectorとすることも可能である。
- Number()<br>
  .innerTextなどで拾ったString要素を、数字に変換することができる。
- **配列へのオブジェクトの格納**<br>
  配列内にはオブジェクトを格納することができ、その各要素の呼び出しは「配列`[インデックス番号]`.要素名」で行うことができる。
- **.style.display="none"**<br>
  表示したくない要素を意図的に隠すことができるCSSの機能をJSで表記したもの。<br>
  今回、配列内にidも格納しているため、表示の際にidを隠すため利用。
- **pointerEvents**<br>
  カーソルの反応を受け取り方を決める、CSSの機能をJSで表記したもの。<br>
  今回ボタンに画像要素をappendしたため、画像の位置をクリックすると、削除したい`<li>`ではなくボタンを親要素として拾うようになってしまった。<br>
  対策として、pointerEvents:noneを利用し、画像に対してはいかなるカーソル操作のイベントも受け付けないよう設定した。<br>
  これによって、画像の位置をクリックしても画像自体に対するイベントは無視されるため、その下のボタンにclickのイベントが渡されることとなった。

###　その他

- md記述での記号<br>
  `<>`や`[]`の記号を使うと表記が乱れることを理解した。<br>
  「`」で使用したい記号の両端を囲むことで、文字列の一部として表示することができる。
- md記述での改行<br>
  `<br>`を記述しなければ改行が行われない。
